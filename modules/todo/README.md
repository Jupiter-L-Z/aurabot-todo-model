# Todo 待办

Aurabot 的独立扩展模块，不依赖 Brain 模块。为聊天创建即时或定时待办，并可选择生成早安、晚安问候计划。需要 Aurabot 1.2.0 或更高版本及 Node.js 22.2 或更高版本；具体版本兼容性尚待市场工具验证。

## 安装

将本目录作为 `modules/todo/` 放进 Aurabot 数据目录，包含 `index.mjs`、`todo.mjs` 和 `panel.js`。在 Aurabot 的已安装模块中启用 Todo。通过模块市场发布后的安装方式以市场页面为准。模块需要访问 Aurabot 的内部聊天中枢，不是独立运行的程序。

## 使用

在聊天中提出提醒或后续事项，模型可以使用 `todo_add`。格式：

```text
来源对话|念头和原因|目的对话|时间|次数|重复间隔分钟
private:123|提醒学习|private:123|14:30|3|5
private:123|需要跟进的事情|private:123|0|1
```

时间填 `0` 表示立即安排；次数为 `-1` 表示每天；第六段可省略，普通多次任务默认间隔一分钟。跨聊天需要主人或在模块设置中的跨对话白名单授权。安排任务不等于模型已完成后续工作。

面板提供计时、记录和撤回，以及默认关闭的早安与晚安计划。启用时可分别配置候选名单与人数；候选人须在 Aurabot 的私聊白名单中。名单留空时使用最近两天有消息的私聊。问候会触发模型，尝试以语音回复；不保证模型一定发出语音。启用此功能前请确保收件人同意接收主动问候。

## 数据与限制

待办保存在 Aurabot 的 `modules-data/todo/todo.json`，模块不直接向外部网站发送数据，但会调用宿主聊天中枢，可能产生模型请求和 QQ 消息。早晚计划会读取本地聊天流水及配置。代码使用文件系统、插件配置与宿主内部对象。

电脑和 DSH 必须运行才能触发任务。重启后会恢复未完成任务，逾期任务尝试触发一次；如果午夜不在线，当天问候计划不会补生成。目前任务在递交给聊天中枢前即被推进或标记完成，投递失败不会自动重试，不能用于需要可靠交付的提醒。跨聊天任务不会自动保证询问结果返回来源对话。

卸载模块不会主动删除本地待办；请根据 Aurabot 的数据管理方式自行处理。
